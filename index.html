High-Performance Limit Order Book Architecture

C++20 & Concurrency
01

Bounded Lock-Free Queue

Engine/BoundedQueue.h

Thread-safe Single Producer Single Consumer (SPSC) ring buffer with std::atomic<size_t> head and tail indices with power-of-two masking. Avoids heavy mutex locking on critical path.

02

Matching Engine & Worker

Engine/Engine.h

Dedicated processing worker executing on a pinned thread. Commands are dequeued and processed in batches up to 30,000 operations before triggering matching, maximizing L1/L2 cache locality.

03

Price-Time Priority Order Book

Order_Book/OrderBook.h

Uses std::map<Price, PriceLevel> for ordered price levels and doubly-linked std::list<OrderPointer> for FIFO queues. An unordered_map<IdNumber, iterator> enables O(1) order cancellation and modification without scanning.

04

Markov-Pareto Order Stream

Order_Generator/MarkovParetoOrderGenerator.h

Synthesizes institutional market flow using a continuous Markov process for mid-price drift combined with a Pareto heavy-tailed distribution for realistic volume clumping and flash spikes.

Matching Logic Flow (FIFO Price-Time Priority) C++ Core 
// OrderBook::matchOrders()
while (!bids.empty() && !asks.empty()) {
    auto bestBidIt = bids.begin();
    auto bestAskIt = asks.begin();
    
    if (bestBidIt->first < bestAskIt->first) break; // No crossing spread

    auto& buyOrder = bestBidIt->second->orders.front();
    auto& sellOrder = bestAskIt->second->orders.front();

    Quantity tradeQty = std::min(buyOrder->getRemainingQuantity(), sellOrder->getRemainingQuantity());
    buyOrder->fill(tradeQty);
    sellOrder->fill(tradeQty);

    if (buyOrder->isFilled()) bestBidIt->second->orders.pop_front();
    if (sellOrder->isFilled()) bestAskIt->second->orders.pop_front();
}
